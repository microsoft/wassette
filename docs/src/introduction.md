# Wassette Documentation

Welcome to the Wassette documentation! This book provides comprehensive information about Wassette, a security-oriented runtime that runs WebAssembly Components via Model Context Protocol (MCP).

## What You'll Find Here

- **[What is Wassette?](./overview.md)** - Learn about Wassette's purpose, design philosophy, and core concepts
- **User Guide** - Installation instructions and setup for different platforms
- **Design & Architecture** - Deep dive into Wassette's architecture and security model
- **Contributing** - Information for developers who want to contribute to the project

## Quick Start

If you're new to Wassette, we recommend starting with the [What is Wassette?](./overview.md) section to understand the core concepts, then moving on to the installation guide for your platform.

## Getting Help

- Check out our [examples](https://github.com/microsoft/wassette/tree/main/examples) in the main repository
- Join the discussion on [Discord](https://discord.gg/microsoft-open-source) in the `#wassette` channel
- Report issues on [GitHub](https://github.com/microsoft/wassette/issues)
